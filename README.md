## インストール

1. ダウンロードした zip を**右クリック →「すべて展開」**で展開してください。
2. 展開したフォルダを、パソコンの好きな場所に置いてください(デスクトップで構いません)。
3. フォルダの中の **`Install.bat` をダブルクリック**してください。

これだけです。詳しくは同梱の `インストール方法.txt` をご覧ください。

### 事前にご用意いただくもの

- **CONTEC社製 測定ボードのドライバ** — 装置に付属のCD、またはCONTEC社の公式サイトから、お使いのボードの型式に合ったものを先に入れてください。このインストーラーはドライバを入れません。
- **Python** — 定性定量・GPC解析ツール「AnalyzeReport」をお使いになる場合のみ必要です。測定・チャート表示など本体の基本機能には要りません。

### はじめての起動

初回のみ**認証画面**が出ます。画面に出ている4桁の英大文字コードを弊社または特約店へご連絡ください。折り返しお送りする4桁の確認コードを入力すれば、以後この画面は出ません。
